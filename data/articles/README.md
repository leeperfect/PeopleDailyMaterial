# 成品文章目录说明

`data/articles/` 按内容来源和使用状态管理公众号成稿。

```text
data/articles/
├── 人民日报系列/              # 当前可继续编辑、待发布的人民日报选题文章
├── 热点系列/                  # 当前可继续编辑、待发布的热点分析文章
├── 往期文章/
│   ├── 人民日报系列/          # 已发表的人民日报选题文章
│   └── 热点系列/              # 已发表的热点分析文章
├── 文章索引.md                # 两个系列共用的查找入口
├── 选题库.md                  # 公众号选题总表
└── 选题库-精筛说明.md        # 选题精筛记录
```

## 编号规则

- 人民日报系列沿用数字序号，当前下一篇使用 `31`。
- 热点系列单独使用“热点+数字”，当前下一篇使用 `热点4`。
- 文章移入往期目录后保留原编号，不重新编号。

## 归档规则

文章发表后由老师手动移动到对应的往期系列目录。移动后同步更新 `文章索引.md`，过程稿和媒体资产中的引用路径也要指向新的归档位置。
