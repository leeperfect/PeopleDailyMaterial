# 碳达峰从单项减排到系统转型

## 来源边界

本选题完整阅读5篇《人民日报》材料，并补充`Codex 教研速读｜2026-07-28`。材料分工如下：

- **行动总纲**：《“十五五”碳达峰行动方案》提供2030年目标、5方面任务和6类重点工程。
- **落实机制**：国家发展改革委答记者问提供责任分工、跟踪调度和动态优化要求。
- **关系方法**：延伸阅读提出供给与需求、全面与重点、硬件与制度三组关系。
- **循环支撑**：循环经济规划答记者问提供减量、再利用、回收和产业升级链条。
- **需求牵引**：绿色消费理论文章提供标准、标识、激励和绿色金融方向。

事实边界：

- 到2030年单位国内生产总值二氧化碳排放比2025年降低17%、非化石能源消费占比达到25%，属于目标值。
- 碳达峰是排放达到峰值后稳中有降，不等于碳中和。
- 2025年循环经济数据是阶段性成效，2030年指标是规划目标。
- 绿色积分、绿色金融和统一标识属于制度建设方向，不能写成全国统一成熟模式。
- “新三样”废弃物回收是新问题，不能因产品本身绿色而忽略全生命周期风险。
- 碳排放要素配置应放在市场机制和综合效益语境中，不能转写为简单行政摊派。

## 选题判断

碳达峰题常见写法是把“节能、减排、关停、出行”并列罗列。问题在于：

- 没有处理能源安全和绿色转型的关系；
- 没有解释新能源为什么还需要电网、储能和互济；
- 把传统产业改造写成简单退出；
- 只管生产排放，不管资源全生命周期；
- 把绿色生活变成对个人的道德劝说；
- 只提目标，不写核算、价格、市场和责任。

> **碳达峰不是单项减排工程，而是能源供给、产业生产、资源利用、消费需求和治理制度共同重塑。**

## 写作逻辑

### 第一层：先处理关系

用三组关系阻断运动式减排：

- 供给变革与需求升级；
- 全面转型与重点突破；
- 硬件工程与制度环境。

### 第二层：再建立转型链

> **能源供给转绿 → 产业和重点领域用能提效 → 资源循环降低投入 → 绿色消费牵引供给 → 核算、价格、市场和责任形成闭环**

### 第三层：最后落到执行

从摸清底数、识别重点、工程清单、责任分工，到动态监测和及时校准，避免层层加码和一刀切。

## 可迁移公式

考场总公式：

> **调能源 → 改产业 → 抓领域 → 促循环 → 引消费 → 建机制**

政策落实公式：

> **目标定向 → 工程筑基 → 科技解题 → 金融分险 → 市场激励 → 责任闭环**

## 可用事实

- 《“十五五”碳达峰行动方案》提出到2030年的两项核心目标。
- 行动方案部署能源、产业、重点领域、支撑保障、各方合力5方面任务。
- 重点工程包括省间电力互济、煤炭清洁替代、重点行业节能降碳、低碳零碳供热制冷和绿色照明、零碳运输走廊、基础能力提升。
- 2025年主要再生资源回收利用量超过4.1亿吨。
- 2025年资源循环利用产业产值达到5万亿元。
- 循环经济规划提出到2030年主要再生资源年循环利用量达到5.1亿吨、产业产值达到8万亿元，均为规划目标。

## 关系辨析

- **碳达峰不等于碳中和**：前者是排放达峰后稳中有降，后者是排放与吸收抵消。
- **降碳不等于停止发展**：核心是降低单位产出碳排放，提高发展质量。
- **新能源装机不等于有效供给**：还要有电网消纳、储能和省间互济。
- **传统产业不等于落后产业**：要淘汰的是落后工艺和低效产能。
- **新兴产业不天然低碳**：算力等领域同样需要能效和绿电约束。
- **循环经济不只是垃圾分类**：它贯穿设计、生产、使用、回收和再生。
- **绿色消费不只是个人自觉**：需要标准、设施、供给和激励。
- **目标刚性不等于办法机械**：地方应结合禀赋和产业阶段动态优化。
