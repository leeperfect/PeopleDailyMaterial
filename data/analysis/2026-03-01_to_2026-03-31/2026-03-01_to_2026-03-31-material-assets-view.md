# 2026年3月人民日报素材资产分析

## 一句话判断

3月是全年申论素材的“政策总纲月”。全国两会和政府工作报告把方向讲清楚，正确政绩观把价值坐标校准，新质生产力把发展动能展开，公共服务、生态法治、文化传承和农业现代化则把这些大词落到具体治理场景里。

如果4月适合写“问题如何接住”，那么3月更适合写“方向从哪里来”。后续所有主题文章，都可以用3月材料立论，用4月、5月材料落地。

## 月度主线

3月的材料可以概括为“一份总纲、两条主线、五组案例”。

一份总纲，是《政府工作报告》。它集中提供了2025年工作回顾、“十五五”目标任务和2026年政府工作安排，是全年政策表述的源头。

两条主线，一条是正确政绩观，另一条是新质生产力。前者解决“为谁干、怎么干、如何评价”，后者解决“靠什么发展、如何提质、怎样治理新技术”。

五组案例，是公共服务、农业现代化、统一大市场、生态环境法典、文化公共服务。这些是申论和面试最需要的“落点”：不能只会背权威表述，还要能举例、能拆解、能转成对策。

## 主题一：全国两会与政府工作报告

### 教学评级：S

《政府工作报告》是3月最重要的政策母本。它不适合简单摘句，而适合拆成“年度成绩、问题挑战、发展任务、治理方法”四层。

从2025年工作回顾看，报告里有一批可直接用于申论开头和背景段的数据：国内生产总值增长5%，总量达到140.19万亿元；城镇新增就业1267万人；粮食产量达到1.43万亿斤；高技术制造业、装备制造业增加值分别增长9.4%、9.2%；工业机器人、集成电路产量分别增长28%、10.9%；新能源汽车年产量超过1600万辆；数字经济核心产业增加值占国内生产总值的比重提高到10.5%以上。

从治理方法看，报告反复强调“政策支持和改革创新并举”“既放得活又管得好”“投资于物和投资于人紧密结合”“用改革的办法打通经济循环的卡点堵点”。这些句子适合转成申论高分表达：发展不是单靠投资，也不是单靠技术，而是政策、改革、人才、制度、市场一起发力。

从2026年工作任务看，最值得后续跟进的是六个方向：强大国内市场、发展新质生产力、科技自立自强、全国统一大市场、乡村全面振兴、保障和改善民生。这六个方向基本覆盖申论高频主题。

### 可转译框架

政府工作报告可以拆成：

成绩怎么看 -> 问题在哪里 -> 任务是什么 -> 政策怎么发力 -> 群众如何受益

### 可用表达

- 政策不是孤立发力，而是形成稳预期、扩内需、促改革、惠民生的组合效应。
- 推动高质量发展，既要政策给力，也要改革发力。
- 既要投资于物，也要投资于人，让发展成果最终转化为人的发展能力。

## 主题二：正确政绩观

### 教学评级：S

3月的正确政绩观材料非常系统，甚至比4月更适合作为理论底座。

3月17日《“政绩观问题是一个根本性问题”》给出了价值总纲：正确政绩观源于“政绩观折射价值观”，也“连着发展观”。文章把为民造福、实事求是、尊重规律、久久为功放在一起，特别适合讲申论大作文的立意。

3月20日《“一眼千年”看政绩》把政绩观和文化遗产保护结合起来。正定古城的保护说明，真正的政绩不一定是短期显绩，也可能是在“不容易出政绩的地方出政绩”。这对学生很重要：政绩观不只讲民生服务，也可以讲文化保护、历史责任、长远发展。

3月23日《调研越是走深，政绩越会向实》把政绩观落到调查研究。习近平同志在正定“骑车下乡”，跑遍全县25个公社、220多个大队；文章提醒，调研不是作秀，而是摸清真实情况、发现真实问题、激发真实情感。

3月24日《实事求是贵在“求”》很适合讲“怎么避免拍脑袋”。文章指出，实事求是难在“求”，既有能不能的问题，也有敢不敢、想不想的问题。它能帮学生把“实事求是”写得更有层次。

3月25日《“三拍”本质上是政绩观错位》、3月27日《以正确政绩观审视“三把火”》、3月31日《“政绩冲动症”背后有私心》，构成一组反面案例链：拍脑袋决策、拍胸脯表态、拍屁股走人；新官上任盲目烧火；投资过亿元的城铁站开通没几年就停运。这些材料非常适合面试综合分析题。

### 可转译框架

正确政绩观可以写成五个判断：

为谁干 -> 是否为民造福  
怎么干 -> 是否实事求是  
凭什么干 -> 是否尊重规律  
干多久 -> 是否久久为功  
谁来评 -> 是否群众认可

### 可用表达

- 政绩观不是工作口号，而是权力观、群众观、发展观的集中体现。
- 不容易出政绩的地方，更考验干部的境界、定力和担当。
- 调研走得越深，决策越能落到实处；群众坐得越近，问题看得越真。
- “三拍”看似是方法问题，本质是政绩观错位。

## 主题三：治理办理链与公共服务

### 教学评级：S

3月的公共服务材料不像4月那样集中在养老、托育、医疗某一个场景，而是更强调“治理链条”和“服务半径”。

《从“办理”看治理》可以作为全过程人民民主和治理闭环的范文。文章把代表建议办理写成“民有所呼、政有所应”的制度过程：高质量意见建议来自调研，高成效办理落实依托沟通、协同和反馈机制。它提醒学生，申论中的“办理”不是简单处理材料，而是一套制度化表达和解决路径。

《让公共服务更贴近百姓的生活半径》是公共服务均等化的好材料。四川资中从普惠托育、县域医疗、全龄友好社会切入，把“公共服务是否便捷”转成群众能感知的标准：少跑一趟路、少等一次号、少花一分精力。医共体成立以来，乡镇卫生院门诊量提升10%以上，群众县域内就诊率提高6.6个百分点。

《教育资源如何适配学龄人口变化》提供了教育治理的新角度：2026年、2029年、2032年，初中、高中、高等教育学龄人口将依次达峰。教育资源不能静态配置，而要从被动应对转向主动预警，从静态布局转向动态流动。

《以“共赢思维”服务好新就业群体》与《营造公平有序就业环境》可以组成新就业群体专题。文章提到全国新就业群体总量达8400万人，占职工总数的21%。服务好新就业群体，不只是照顾个体，也是稳就业、促发展、强治理。

《“群众点题”推动办好民生实事》提供了很强的基层治理案例。广西通过群众点题、压实责任、贯通查改治，2025年办成民生实事1.17万件，解决群众急难愁盼问题2.06万个。

### 可转译框架

公共服务和治理办理链可以写成：

群众点题 -> 调研识题 -> 部门领题 -> 协同答题 -> 反馈评题 -> 制度固题

### 可用表达

- 公共服务的好坏，最终要看是否进入群众的生活半径。
- 办理不是把问题“转出去”，而是把民意转化为政策合力和治理效能。
- 均等化不是静态平均，而是跟着人口、需求和生活场景动态配置。
- 服务好新就业群体，是稳就业、优治理、促发展的共同课题。

## 主题四：新质生产力、人工智能与数字基础设施

### 教学评级：S

3月的新质生产力材料非常适合讲“不要把新质生产力写空”。

《新质生产力跑得快，体制机制如何跟上？》讲清楚一个关键点：新质生产力由新技术、新产业、新模式驱动，依赖多种要素协同发力。如果制度环境仍停留在过去，就会出现“新业态跑得快、制度跟得慢”。这篇文章最适合转成申论分论点：发展新质生产力，不仅要技术创新，也要制度创新。

《AI的尽头是电力 电力的优势靠什么》把人工智能、算力和电力联系起来。政府工作报告首次提出“打造智能经济新形态”，并部署“超大规模智算集群、算电协同等新基建工程”。文章还提到，2026年2月9日至15日，中国AI模型调用量达到4.12万亿Token，首次反超美国。这个素材很适合用来说明：AI竞争背后是基础设施、产业体系和能源保障能力的竞争。

《算力供给如何更绿色》进一步把算力和绿色发展连接起来。海南海底数据中心、沙漠光伏基地、西藏数据中心等案例说明，新质生产力不是只讲“快”，也要讲“绿”、讲成本、讲可持续。

《牢牢掌握人工智能发展和治理主动权》则提供治理边界。后续写AI时，可以从“发展与治理并重”的角度展开：既鼓励创新，也完善规则；既拓展应用，也防控风险。

### 可转译框架

新质生产力可以拆成：

技术突破 -> 要素流动 -> 场景应用 -> 产业转化 -> 制度供给 -> 风险治理

### 可用表达

- 新质生产力跑得快，体制机制也要跟得上。
- AI竞争的背后，是算力、电力、数据、人才和制度的综合竞争。
- 数字基础设施既要支撑智能经济，也要兼顾绿色低碳。
- 技术创新越快，治理创新越要及时。

## 主题五：春耕里的新质生产力与农业现代化

### 教学评级：S

3月最有画面感的一组材料，是“春耕里的新质生产力”。

《老杨农资店满满科技感》从一个农资店切入，讲无人机、肥料新品、小微农机和经营转型。它适合告诉学生，新质生产力不是只在实验室，也在农资店、田埂和农户手里。

《抢春分 抓田管 越关口》把老专家和智能农机放在同一个画面里。河南周口商水县121万亩小麦迎来拔节关键期，专家下沉一线，智能农机精细作业，截至3月16日，周口市一、二类苗占比达91.2%。这个案例很适合讲“传统经验 + 数字工具”的协同。

《沙漠边也能种小麦》提供了极强的反差感。塔克拉玛干沙漠南缘的新疆昆玉市，8200余亩小麦种植基地返青保苗率保持在90%以上，指针式喷灌机长380多米，调好参数后自动化运行。它能把农业现代化、节水农业、设施农业讲得很具体。

《做强农业“芯片”，端稳中国饭碗》适合做粮食安全专题。首款国产甘蓝型油菜20K固相基因芯片“中芯油1号”发布，文章还提到玉米品种“中玉303”百亩示范方平均亩产超1000公斤、白羽肉鸡种源从长期依赖进口到自主研发出口。

《人工智能植保员，识别害虫不“脸盲”》把AI落到植保。1000瓦高压汞灯、零下80摄氏度样本冷冻、数以万计的高清害虫影像数据集，说明农业科技并不轻松，也不是一句“数字赋能”就能概括。

### 可转译框架

农业现代化可以写成：

良田 -> 良种 -> 良机 -> 良法 -> 良服

也可以写成：

科技下田 -> 服务到户 -> 数据入链 -> 风险可控 -> 农民增收

### 可用表达

- 新农具进入田间，改变的不只是劳动方式，更是农业生产的组织方式。
- 科技强农的关键，不是技术有没有，而是农民用不用得上、用不用得起、用不用得好。
- 粮食安全要靠藏粮于地，也要靠藏粮于技。

## 主题六：高质量发展、统一大市场与民营经济

### 教学评级：A+

3月经济类材料适合做“宏观政策 + 微观企业 + 区域协同”的组合。

《从一条跨省高速，看长三角互联互通》把统一大市场写得很具体。苏台高速让企业每吨运输成本从110元下降到100元，单运输一项每年降低成本20余万元。更重要的是，文章讲到省际接口、技术标准、建设时序和代建机制，说明统一大市场不是抽象概念，而是规则、设施和协同机制的统一。

《小小焊丝“韧性”强》讲民营企业高质量发展。天津金桥焊材车间生产线速度达到28米/秒，效率是传统生产线近5倍；国内每3根焊条，就有1根是“金桥制造”。这个案例适合讲传统制造业如何靠质量、标准、数字化和差异化增强韧性。

《河南加快建设全国统一大市场循环枢纽》和《“我们看见更长远的未来”》可以作为区域发展和民营经济的政策支撑。

### 可转译框架

高质量发展可以写成：

规则统一 -> 设施互联 -> 要素流动 -> 企业创新 -> 产业升级

### 可用表达

- 统一大市场不是只看市场规模，更要看规则、标准、设施和监管是否协同。
- 民营经济的韧性，来自长期专注、技术积累、质量标准和市场适应能力。
- 区域协同不是简单相邻，而是让交通、产业、政策和服务真正连起来。

## 主题七：生态文明与绿色法治

### 教学评级：A+

3月生态类材料的最大特点，是生态环境法典。

《为中华民族永续发展筑牢法治根基》明确，2026年3月12日，十四届全国人大四次会议通过《中华人民共和国生态环境法典》。这是继民法典之后，我国第二部以“法典”命名的基本法律，共1242个法条。它适合做生态文明专题的权威依据。

《从生态环境法典读懂“绿色叙事”》把法典和民生连接起来。文章强调，良好生态环境是最普惠的民生福祉；从“盼蓝天”到“拍蓝天”再到“晒蓝天”，党的十八大以来我国GDP翻了一番多，PM2.5平均浓度下降59%。这个角度非常适合申论：生态不是远处的山水，而是群众身边的空气、水、噪声、油烟。

《从“双碳”目标到生态环境法典》讲绿色低碳发展编，适合写“在发展中降碳、在降碳中实现更高质量发展”。

《长江畔，百里生态廊道变“宽”了》和《辽宁完成科尔沁沙地综合治理任务超434万亩》提供基层案例。辽宁2025年度完成科尔沁沙地综合治理任务434.04万亩，是年度计划的132%；沙化、荒漠化林草用地平均植被综合盖度分别提升7%和20%。

### 可转译框架

生态文明可以写成：

法治保障 -> 系统治理 -> 减污降碳 -> 生态惠民 -> 长效协同

### 可用表达

- 生态环境法典把绿色发展从价值理念进一步转化为制度规范。
- 生态账本也是民生账本，蓝天、碧水、净土都是群众获得感。
- 生态治理不能单点用力，要跨区域、跨部门、跨层级协同。

## 主题八：文化传承与公共文化服务

### 教学评级：A+

3月文化类材料有两个方向：一是文化遗产保护，二是公共文化服务。

《建立文化遗产与大众的“深连接”》讲故宫文物保护和数字传播。故宫近200万件（套）可移动文物，90%以上属于珍贵文物，占全国珍贵文物的43%以上。文章强调“最小干预”和“预防性保护”，并提到数字多宝阁、《画游千里江山》等传播方式。它适合讲文化遗产保护从“保存”走向“连接”。

《夜校灯火，点亮文化生活》讲辽宁文化夜校。2024年4月辽宁启动市民文化夜校项目，以省文化馆为总校，在多地设立分校，在晚间时段为18至60周岁人群提供文化艺术普及课程。这个案例适合写公共文化服务如何适应上班族的时间和生活场景。

《中小博物馆为何值得看》提供了很好的政策和方法。中小博物馆要以“精、特、新”突围：以精取胜、以特引人、以新求变；还可以通过大馆带小馆、联盟策展、巡回展览实现资源共享。

《文化传承，蕴含增长潜能》提醒，文旅融合不是简单叠加旅游场景与文化符号，而是构建可参与、可沉浸、可延展的文化消费新生态。

### 可转译框架

文化传承可以写成：

保护为先 -> 数字赋能 -> 公共共享 -> 场景创新 -> 价值转化

### 可用表达

- 文化遗产保护既要守住历史真实，也要建立与大众生活的深连接。
- 公共文化服务要从“有场馆”走向“有内容、有时间、有温度”。
- 文旅融合不是贴符号，而是让文化可参与、可体验、可延展。

## 申论教学用法

### 综合分析题

可围绕“如何理解正确政绩观是根本性问题”设题。答题时从价值观、发展观、群众观、作风观四个层面展开。

### 对策题

可围绕“如何提升公共服务与群众需求的匹配度”设题。对策可写成：加强需求研判、动态配置资源、推动服务下沉、强化数字赋能、完善反馈评价。

### 大作文

可围绕“以正确政绩观引领高质量发展”展开。材料可串联政府工作报告、正确政绩观、新质生产力、公共服务和生态文明。

### 结构化面试

可设置四类题：

- 有地方投资过亿元建站，却因位置偏远开通几年后停运，你怎么看？
- 你所在街道要开展“群众点题”办实事活动，你怎么组织？
- 本地想发展AI产业，但算力能耗和监管风险突出，你怎么协调？
- 学龄人口变化导致部分学校生源减少、部分学校学位紧张，你怎么提出建议？

## 后续优先写作建议

1. 先写“正确政绩观：为什么说它是根本性问题”，用3月做理论底座，用4月、5月做案例支撑。
2. 再写“公共服务要进入群众生活半径”，把资中县全龄友好、教育资源动态配置、新就业群体服务串起来。
3. 第三篇写“新质生产力别写空：体制机制、算力电力、农业新农具”，解决考生写作概念化问题。
4. 第四篇写“生态环境法典怎么进申论”，把法治、民生、绿色发展、系统治理讲清楚。
5. 第五篇写“文化传承不是摆出来，而是连起来”，适合公众号和小红书。
