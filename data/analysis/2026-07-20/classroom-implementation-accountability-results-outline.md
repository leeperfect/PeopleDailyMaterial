# 课堂讲解提纲｜抓落实：从任务承接到真实验收

## 一、课程目标

学完后，学员应能完成三件事：

- 识别选择性执行、数字政绩和机械落实的区别与联系；
- 使用“五步责任链”组织申论分论点和面试答题；
- 在案例中区分政策目标、实施方法、数据证据和评价标准。

## 二、开场辨析｜5分钟

呈现两份“成绩单”：

- A地：完成率98%，报表增长明显，但主要完成了容易量化的项目；
- B地：完成率88%，同时化解一项跨部门旧账，群众投诉明显减少。

提问：哪个地方落实得更好？还缺哪些信息才能判断？

讲解落点：单一完成率不能证明真实成效，需要继续看任务完整性、数据质量、实施方法、问题难度和长期影响。

## 三、总框架｜3分钟

> **任务完整承接 → 过程如实记录 → 方法遵循规律 → 难题持续攻坚 → 群众与长效验收**

强调五步是因果链：前一环出现偏差，会直接污染后一环。

## 四、模块一：不搞选择性执行｜6分钟

### 讲解重点

- 容易出彩、立竿见影的任务为什么更受偏爱；
- 硬骨头、慢变量为何容易被推迟；
- 选择性执行怎样破坏政策“一盘棋”。

### 核心辨析

> **完整执行的是政策目标、责任和底线；因地制宜调整的是合法合规的实施方法。**

### 课堂追问

“如果基层客观上资源不足，无法同时推进所有任务，是否属于选择性执行？”

参考回应：应依法依规区分轻重缓急、制定阶段计划并及时报告协调，不能因资源有限而隐瞒、放弃或只选容易出成绩的事项。

## 五、模块二：数据必须实打实｜6分钟

### 四类数字游戏

- 造数字；
- 追数字；
- 摆数字；
- 催数字。

### 数据核验五步

> **统一口径 → 标明来源 → 交叉验证 → 现场复核 → 责任追溯**

### 案例

南通“凡考必核”：不同来源的数据分级管理，基层自报数据接受联合抽查。

### 课堂追问

“数据不好看，是否说明工作一定没做好？”

参考回应：数据是重要证据，但需结合基础条件、结构质量、现场变化和群众感受综合判断；不能因数据不理想掩盖问题，也不能唯排名否定实干。

## 六、模块三：真抓不能蛮干｜5分钟

### 三组关系

- 目标不打折，方法可优化；
- 急事快办，长期任务分阶段办；
- 压实责任，不等于层层加码。

### 科学落实四步

> **调查研究 → 分类施策 → 试点验证 → 动态纠偏**

### 易错提醒

久久为功不是拖延。当务之急要及时处置，长期任务也要有阶段节点和进度反馈。

## 七、模块四：敢接难事和旧账｜5分钟

### 难事三类

- 跨部门硬骨头；
- 见效慢的基础性工作；
- 跨任期历史遗留问题。

### 六步理账法

> **查资料 → 访当事人 → 厘责任 → 分类型 → 定方案 → 建反馈**

### 案例

达拉特旗设置9方面49条交接事项，对难点和遗留工作继续明确时限、举措与责任人。

### 核心句

> **岗位可以变，责任链不能断；干部可以换，群众的问题不能重新排队。**

## 八、模块五：怎样检验真实成效｜5分钟

### 四维成绩单

- **结果**：问题是否解决、目标是否完成；
- **过程**：程序、协同、成本是否合理；
- **群众**：服务对象是否有真实获得感；
- **长效**：是否留下债务、风险和新的旧账。

### 案例

江苏“三张考卷”纳入满意度评价，参考12345办理情况；淮安对重大项目开展全生命周期考核。

### 边界

群众满意不能替代法治和专业标准，应与客观数据、公共利益和长期效果结合。

## 九、面试模拟｜5分钟

### 题目

某地为落实一项民生政策，将上级目标逐级加码，短期完成率明显提高，但基层反映重复填表增多，部分群众仍未享受服务。你作为督查组成员，怎么办？

### 答题框架

1. 核政策：核对目标、口径和责任边界；
2. 查实情：比对报表、业务记录、现场和群众反馈；
3. 纠偏差：停止不合理加码，取消重复报表；
4. 补缺口：对未覆盖对象建立台账、限时办理；
5. 改考核：纳入实际效果、基层负担、群众感受和长期影响；
6. 做反馈：公开整改进展，复盘制度原因。

## 十、课堂收束｜2分钟

让学员用一句话完成定义：

> **抓落实，就是完整接住责任、真实面对问题、科学推进任务、持续解决难题，并让群众和时间共同验收。**

课后练习：以“整治形式主义为基层减负”为主题，用五步责任链写一段300字对策分析。
