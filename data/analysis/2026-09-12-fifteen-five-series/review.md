## 三、本次真正补了哪六个选题

新选题已在选题卡中标明与旧稿的区别；每题配置3篇独立来源，纲要不计入这3篇，防止各题都靠同一篇纲要凑数。

### 第01讲｜《人民日报》深度分析【“十五五”规划指标】：数字背后，哪些是方向、哪些是责任

只解决怎么读规划、辨指标与责任；第24讲解决怎么把目标组织成实际工作。

分析路径：认清文本 → 分清指标 → 看清主体 → 读出联系 → 用于分析。

### 第07讲｜《人民日报》深度分析【有效投资】：楼建好了，怎样让人员、能力和服务一起跟上

研究项目和预算怎样同时安排设施、人员、能力与持续服务；不同于第91篇城市空间运营，也不同于技能培训的到岗流程。

分析路径：从需求起步 → 让物和人匹配 → 算完整账 → 接上发展 → 用于分析。

### 第08讲｜《人民日报》深度分析【盘活存量】：闲置的房屋和设施，怎样重新变成有用的服务

首讲聚焦存量资源的清查、权属用途、需求匹配和运营责任；第91篇从已完成城市更新后的运营出发，本讲从尚未盘活的资源出发。

分析路径：查清闲置 → 厘清用途权属 → 匹配真实需求 → 建立使用责任 → 用于分析。

### 第09讲｜《人民日报》深度分析【制度型开放】：货物过了关，规则、标准和服务还要打通什么

聚焦规则衔接与制度试验；第35篇品牌出海聚焦企业能力和价值链，不以它替代制度分析。

分析路径：识别堵点 → 把握开放方向 → 观察试验机制 → 兼顾便利与监管 → 用于分析。

### 第17讲｜《人民日报》深度分析【居民增收】：发展成果怎样更稳定地进入普通家庭的收入

聚焦收入从哪里来、怎样分、如何保持可持续；不复述第85篇的促消费供给，也不重复联农带农这一农业切口。

分析路径：先看收入来源 → 让能力对应回报 → 拓展经营与财产收益 → 理解分配调节 → 用于分析。

### 第18讲｜《人民日报》深度分析【住房品质】：从有地方住到住得安心，住房供给要改变什么

住房供给、品质标准与全生命周期责任是主线；与第91篇社区空间运营区分，住房市场报道不转成房价预测。

分析路径：识别住房需求 → 建立品质尺度 → 推进存量更新 → 落实长期责任 → 用于分析。

第84篇已包含规划方向、年度重点、项目政策、责任资源、民生风险的执行链，故直接承接第24讲。第36篇教育“十五五”已在往期目录，承接第14讲。第55篇同时有当前过程版本和往期稿，使用索引中的正式入口，不将过程版本计算为另一个选题。

**建议待写顺序：01规划读法 → 13养老照护 → 07有效投资 → 10联农带农 → 17居民增收 → 18住房品质 → 08盘活存量 → 21绿色转型 → 09制度型开放。** 这是9个待写位置，包括6个本次新增、3个已有选题。目录顺序仍保持24讲的知识结构，旧稿通过专题串读连接，不自动改名重发。

先让导读把全图交代清楚，再用养老、农业、就业、创新等熟悉主题吸引读者进入。每篇开头给出生活或工作中的具体问题，中后段再给公考教学转译。发布后优先同龄比较首7天阅读、分享、收藏、新增关注，满30天再比较搜索和转粉表现。

## 五、每一讲采用什么共同结构

1. **一个真实问题**：用人民日报报道中的人物、场景或冲突开场，事实日期写清。
2. **一张规划定位卡**：说明对应哪几章、解决什么发展问题，区分目标、举措和实施进度。
3. **一条分析链**：解释原因、制度机制、执行动作和作用条件，避免列举口号。
4. **三篇以上材料相互支撑**：通常采用解读、实践、评论的组合，材料承担不同任务。
5. **一次教学转译**：正文第六节沿用“六、国考省考申论面试怎么用”，给分析框架、具体动作和适用边界。
6. **一个串读连接**：指向前后讲及已有细分稿件，避免各篇成为孤立材料。

例如第07讲可接在养老照护之后：照护为何缺服务 → 设施与人员的关系 → 投资结构和持续经费 → 项目效果怎样评价 → 迁移到托育、医疗与教育。其后第17讲解释人的能力提升怎样进入收入，让专题之间有可追问的联系。

## 六、核验口径与后续使用
