# 91｜《人民日报》深度分析【城市更新后半程】：空间建好了，服务、运营和居民参与还要接上

上海一个老旧小区完成环境改造后，留下了一间18平方米的门卫室。

房子并没有消失，却渐渐闲置，后来成了堆放杂物的地方。直到专业团队走进社区，把它改成小型美术馆，居民参与起名，青少年担任志愿讲解员，社区学校又接上艺术讲座和亲子工作坊，这个每天都有人路过的小空间才真正活了起来。

这段经历很像许多城市更新项目：施工结束时看上去已经完成，真正的考验却刚开始。

谁会来？里面提供什么服务？谁负责日常运营？电费、维护费和人员成本从哪里出？居民觉得不好用，谁来调整？这些问题没有答案，再漂亮的空间也可能重新空下来。

**城市更新有两次“交付”：第一次交付空间，第二次交付长期可用的生活。**

> **城市更新后半程的完整逻辑是：体检问需 -> 服务嵌入 -> 业态适配 -> 多方运营 -> 资金平衡 -> 动态评估。**

## 一、建设前先问需求：别等空间建好再寻找用途

城市更新最怕一种顺序：先定项目、先画效果图，建好之后再问居民“这里适合做什么”。

需求如果进入得太晚，空间和服务就容易错位。老年人多的社区可能缺的是食堂、助浴和健康服务，却建成了使用率不高的展示厅；孩子多的社区需要托育和活动场地，最后留下的却是一处只适合远观的景观。

上海市民新村改造时，351户居民的诉求各不相同。社区工作人员入户记录“民意账本”，设计方案打磨20多稿，最终形成超40种户型。武汉青和居则通过持续敲门掌握老人、家庭和楼栋的新需求，再把需求清单与资源清单对接成项目清单。

这些做法说明，问需不能只是开工前开一次座谈会，而要贯穿更新全过程：

- **建设前**，通过城市体检、入户走访和居民议事找准问题。
- **设计中**，让居民、专业人员和运营主体共同校正功能。
- **使用后**，继续收集新需求，允许空间和服务随之调整。

**先问谁来用、为什么用，再决定建什么，能少走很多弯路。**

## 二、空间建成后接服务：有房间不等于有服务

一间活动室挂上牌子，不会自动变成养老服务中心；一个展厅装好灯光，也不会自己产生展览。

空间提供的是容器，服务需要人员、内容、时间表和标准。

上海的门卫美术馆持续换展，并有志愿讲解、艺术讲座和亲子工作坊。沈阳寄闲艺术馆每天开放8小时，除了常设展览，还开展专题展和非遗手作课堂。另一处社区把闲置锅炉房改成综合服务体，接入社区食堂、幸福课堂和养老服务。

三个案例的共同点，是在空间方案之后继续回答四个问题：

1. 主要服务哪类居民？
2. 由谁提供专业服务？
3. 一周、一个月怎样安排内容？
4. 服务质量和安全由谁负责？

养老、托育、文化、健康和便民服务不能成为竣工后的“装饰项”。它们要在设计阶段就进入面积、设备、人员和预算安排，开门之后还要有稳定的服务清单。

**空间被使用，才有公共价值；服务能持续，更新才真正进入生活。**

## 三、业态要适宜：人气不是靠塞满商铺制造的

城市更新需要活力，也需要一定的经营收入。但“导入业态”不等于哪里空就开店，更不等于每条老街都复制同一套咖啡、文创和网红打卡。

成都地铁利用闲置和碎片空间时，优先引入烘焙、简餐、便利店、鲜花和生活用品等适配通勤节奏的轻量业态，同时把行李寄存等服务接入站点。杭州留下老街则围绕本地文脉，布局非遗、茶食、阅读、展览和民宿，并通过雅集、讲座等活动维持内容更新。

业态合不合适，可以看四件事：

- 是否解决周边居民和使用者的真实需求。
- 是否服从交通、消防、噪声和空间承载等安全边界。
- 是否与本地文化、周边商业形成差异，而非同质竞争。
- 是否能提供合理收益，承担一部分运营和维护成本。

商业可以为公共空间补充人气和收入，却不能挤走养老、托育、休憩等基本服务。历史街区更要守住文脉和居民生活，不能用游客流量代替社区感受。

**好的业态不是看上去最热闹，而是与这块空间、这群人和这座城市相互适配。**

## 四、多方共运营：有人牵头，也要有人长期履责

建设阶段通常有项目单位、施工单位和验收标准。项目一结束，责任链却可能突然变模糊：产权人只管房屋，物业只管保洁，运营方只管活动，居民有意见又不知道找谁。

城市更新后半程需要一张清楚的责任表：

- **公共部门**负责基本公共服务、规则制定、资源协调和监督评价。
- **产权人**负责房屋安全、资产使用边界和必要维修。
- **运营主体**负责内容供给、人员管理、日常开放和经营秩序。
- **物业与社会组织**承接环境维护、社区服务和专业支持。
- **居民**通过议事、志愿服务和评价参与共同治理。

北京草厂胡同引入酒店后出现空调外机噪声，居民代表、街道社区和酒店经理多次协商，随后建立联动响应机制。空间里的新业态带来了活力，也产生了新问题；运营机制的作用，就是让这些问题有人发现、有人协调、有人整改。

运营前置也很重要。让运营主体在设计阶段参与，不是把公共责任推给市场，而是提前考虑出入口、设备、能耗、维修和活动需求，避免建成后反复改造。

**共同运营不是责任平均分摊，而是每个主体都知道自己该做什么、出了问题由谁接住。**

## 五、把长期账算清：既要有钱维护，也要用效果校准

项目建设有预算，长期运营同样有成本。人员工资、水电能耗、设备维修、内容更新、安全保障，哪一项都不会因为竣工而消失。

上海市民新村改造由财政资金、低息贷款和地下车库等经营性资产租金共同支持。北京一处老旧小区面对居民对物业服务的疑虑，采取“先服务、后收费”，用实际服务建立信任，截至2025年底物业费收缴率达到96.08%。池州一项海绵城市项目则由社会资本方承担建设并负责10年运营维护，尝试减少建设与运维脱节。

这些案例提供了一个基本思路：

- 公益性、基础性服务由稳定的公共投入托底。
- 停车、充电、社区商业、场地租赁等合理收益，可用于反哺维护。
- 需要居民分担的费用，应公开服务清单、收费规则和资金用途，并经过协商。
- 专业运营获得合理回报，同时接受服务标准和公共目标约束。

钱的安排要公开，效果也要持续看。

城市更新不能只验收一次。建成半年、一年后，还应回头检查：空间每天有多少人使用，老人和儿童能否方便到达，设施是否完好，活动是否稳定，投诉有没有处理，周边租金和生活成本是否给原有居民带来压力。

如果使用率长期偏低，就要调整功能；如果商业挤压公共服务，就要修正规则；如果维护费用超出承受能力，就要重新安排运营方案。

**后评估不是给项目补一张成绩单，而是让更新继续改、继续适应生活。**

## 六、国考省考申论面试怎么用

遇到城市更新、老旧小区改造、完整社区、历史街区保护等题目，不能只写完善基础设施、优化城市环境。可以直接使用这套公式：

> **需求决定功能 + 服务填充空间 + 业态支撑运营 + 多方明确责任 + 多元覆盖成本 + 评价推动调整**

### 申论分论点

- **问需在前**：开展城市体检和居民议事，让真实需求进入项目设计。
- **服务接续**：围绕人口结构导入养老、托育、文化和便民服务。
- **业态适配**：统筹公共功能、商业活力、文化保护和安全承载。
- **责任清晰**：建立公共部门、产权人、运营主体、物业和居民共同参与的责任链。
- **长效保障**：完善多元投入、合理分担、运营评价和动态调整机制。

### 面试题示例

> 某老旧小区更新后新建了社区活动中心，但开放半年使用率不高，运营单位称经费不足，居民反映活动与需求不符。领导让你牵头改进，你怎么办？

可以按六步回答：

1. 查看原规划、资金、运营合同和服务清单，了解使用率低的具体时段与人群。
2. 通过走访、议事会和问卷了解老人、儿童、上班族等群体的实际需求。
3. 邀请专业机构重新评估空间功能，调整开放时间、服务内容和活动排期。
4. 明确产权、物业、运营和社区各方责任，建立问题转办与反馈机制。
5. 测算人员、能耗、维护和活动成本，统筹公共投入、经营收益和合理分担。
6. 设置使用率、服务覆盖、满意度和设施完好率等指标，定期复盘并公开结果。

### 使用边界

- 不把城市更新等同于商业开发。
- 不把居民参与停留在一次意见征集。
- 不用短期客流代替长期社区活力。
- 不让商业收益承担全部公益服务责任。
- 不把竣工验收当作治理终点。

## 结尾

一座建筑修好，一片街区变美，当然值得高兴。但城市每天都在使用中变化：居民会变老，孩子会长大，新业态会进入，新的矛盾也会出现。

城市更新因此没有一个一劳永逸的完成时刻。

**把空间交付给生活，把服务交付给居民，把运营交付给清楚的责任和长久的机制，更新成果才不会停在竣工照片里。**
