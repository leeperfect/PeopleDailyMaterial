# 选题复盘｜《人民日报》深度分析【旅居经济】

## 一、选题卡要点

- 标题：《人民日报》深度分析【旅居经济】：风景能把人吸引来，什么才能让人住下来
- 切入角度：从游客要长住而非短暂打卡的需求变化，分析生活服务、季节性供给和本地居民利益的平衡。
- 明确边界：
  - 承接县域及银发主题，但不能把两类历史高阅读简单相加；
  - 区别于既有旅游承载力和县域消费选题；
  - 主攻"从游客到临时居民"的服务转换；
  - 不把旅居包装成旅游地产。
- 指定结构：需求变了 → 供给按人配置 → 旺淡季弹性安排 → 融入而非隔离 → 本地人也要受益。

## 二、运营背景判断

- 参考 `data/data_analysis/overview.md` 与 2026-09-08 运营报告：县域主题（87）与银发相关主题（14、39）均属长期高表现母题，推荐方向是"考试高频母题 + 真实问题切口 + 纠正常见误区"。
- 本选题的独立切口是"服务转换"：人还是那批人（避寒老人、县域青年、数字游民），但问题从"有没有"换成"从游客到临时居民，服务怎么换轨"。这个切口在 87（县域消费的供给下沉）和 21（服务消费的生活半径）中均未覆盖。
- 目标读者画像：被"旅居"种草的普通人（要不要去、去了会遇到什么）+ 公考学习者（新业态治理分析框架）。开头走普通人视角，教学转译集中在第六节。

## 四、主线逻辑链设计

- 读者常见误区：把旅居当"旅游的加长版"，以为风景好就能留住人；把供给当"建房子"，一热就扩建；把旅居者当纯消费者，忽视其创业参与可能；把本地人当背景板，忽视利益平衡。
- 主线（因果递进链）：

> 需求识别（长住要什么）→ 供给分层（按客群配置）→ 弹性承接（旺淡季转换）→ 关系融入（从客人到熟人）→ 利益共生（本地人受益）

- 递进关系说明：第一节立"需求变了"的判断；第二节从需求分化推供给分层；第三节从供给的时间约束（潮汐属性）推弹性安排；第四节从"住得下"推"留得住"（连接与参与）；第五节从旅居者单方视角切换到本地居民，完成"共生才可持续"的闭环。每一节解决上一节遗留的问题，不是并列观点。
- 一句话公式：**风景决定人来不来，生活决定人留不留。**

## 五、五节结构与素材分配

1. 需求变了：选择标准从"值得一看"到"适合长住"（来源3）；医疗、交通、社交与日常生活清单（来源3+来源2：医疗服务中心、绿色转诊通道、最后一公里、公共文化空间、15分钟旅居生活圈）。深化点：游客要体验，居民要确定性。
2. 供给按人配置：气候资源决定模式（来源2）；三亚康养复合业态 vs 广西北部湾帆船冲浪（来源3）；旅居+康养产品（来源2）；云南细分客群支持（来源1）。深化点：需求颗粒度，避免千城千村一面。
3. 旺淡季弹性安排：潮汐属性（来源3）；错误做法是简单扩建扩容；曲靖麒麟区设施弹性（旺季接待、淡季回归公共属性）；全季旅居路线破解审美疲劳（来源3）；城市存量盘活与旅创资产库（来源2+来源1）。深化点：接待能力是可转换能力。
4. 融入而非隔离：文化连接（公共文化空间、非遗植入场景，来源3+2）；事业连接（云南20条：人才库、机会清单、训练营、创业贷，来源1）。深化点：身份从消费者到参与者，停留变成参与。
5. 本地人也要受益：物价上涨、交通拥堵、竞争压力（来源3）；乡村整村运营让农民获益（来源2）；共生共荣判断（来源3）。深化点：成功的标准是本地人分享到收益。

## 六、教学转译设计

- 总公式：旅居经济 = 需求识别 → 供给分层 → 弹性承接 → 关系融入 → 利益共生。
- 申论三个动作：需求转换立论（"从值得一看到适合长住"）、潮汐属性写供给对策（弹性供给优于扩建扩容）、共生共荣写可持续（本地居民从旁观者变受益者）。
- 面试题：某县旺季旅居游客大量涌入，物价上涨、公交拥挤、本地商户不满，牵头处理怎么办。五步：摸底数 → 保基本 → 弹性扩供给 → 疏通机会 → 建长效机制。
- 高分表达储备：潮汐属性、弹性供给、共生共荣、15分钟旅居生活圈、绿色转诊通道、全季旅居、从游到居。

## 七、与既有选题的区分核验

- 与 87《县域消费》区分：87 讲供给、物流、服务跟着需求下沉，落点是"下沉通道"；本篇落点是"长住人群的服务换轨"，核心矛盾是游客逻辑与居民逻辑的差异。
- 与 21《服务消费》区分：21 讲把好服务嵌入生活半径，落点是"服务半径"；本篇落点是"季节性波动下的弹性承接与利益平衡"。
- 与 14、39《银发经济/养老》区分：银发只是旅居客群之一（三亚避寒养老），本篇客群覆盖康养老人、青年旅创者、文化艺术人才等多层，不做两类高阅读的简单相加。
- 与既有旅游承载力相关选题区分：承载力讨论"接待上限"，本篇讨论"服务转换"，明确不写"限流"框架。

## 八、风险与用语注意

- 不引用理论文章开头的领导人语录表述，只用其产业观点，规避高风险用语。
- 不把旅居包装成旅游地产，不出现"买房投资""资产升值"引导；"不应视作旅游地产的翻版"的提醒性表述在正文第二节以"不是换个名字搞旅游"的口径体现。
- 康养、理疗相关表述仅作业态事实转述，不作健康功效承诺。
- 云南20条措施一律用"出台、明确、要求、推动"等部署动词，不虚构成效数据。
- 曲靖、三亚、广西北部湾均保留地名与主体，不夸大为全国普遍做法。
- 三篇来源均为 2026-07 至 2026-09 的近期报道，时间跨度小，不虚构历史数据链。
