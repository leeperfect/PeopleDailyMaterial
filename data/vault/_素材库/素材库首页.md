## 📝 如何标注文章

在阅读文章时，使用以下 Callout 语法标注你觉得重要的内容：

### 标注金句
```
> [!金句] 金句
> 这里粘贴你觉得精彩的句子
```

### 标注案例
```
> [!案例] 案例
> 这里描述事实案例
> **主题**: 相关主题
> **适用**: 适用的论点
```

### 标注修辞手法
```
> [!排比] 修辞-排比
> 这里粘贴精彩的修辞句式
```

### 标注写作框架
```
> [!abstract] 框架
> 这里描述文章的写作结构
```

### 标注专题归类 🆕
```
> [!专题] 专题-科技创新
> 这篇文章与人工智能在政务服务中的应用相关
> 可作为"数字政府"专题的素材
```

标注完后，在终端运行：
```bash
python3 extract_materials.py --collect-annotations
```
即可自动汇总到 `_素材库/我的标注/` 文件夹。

## 🔧 常用命令

```bash
# 全量提取（所有文章 → 金句+案例+写作方法+热点专题）
python3 extract_materials.py

# 只处理某一天的文章
python3 extract_materials.py --date 2026-04-01

# 只收集人工标注
python3 extract_materials.py --collect-annotations
```
