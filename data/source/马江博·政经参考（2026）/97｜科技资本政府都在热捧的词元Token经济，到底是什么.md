# 97｜科技、资本、政府都在热捧的词元（Token）经济，到底是什么？

**Course:** 未命名课程

## 学习理想国·Perfect，你好

欢迎来到《政经参考》，我是马江博。

今天，我们来谈谈最近半年一个非常热的词——Token，中文翻译叫“词元”。

最近科技圈、资本圈，包括各地方政府，都在频频热捧这个词，某种意义上，它已经成为新纪元的代表。

2026年3月，国家数据局局长公布了一组惊人数据：中国日均词元调用量已突破140万亿，而两年前这个数字还仅仅是1000亿。两年之间，增长超过一千倍。

同一个月，国家数据局正式将英文Token的中文译名规范为“词元”，并将它定性为“智能时代的价值锚点”和连接技术供给与商业需求的“结算单位”。

这标志着，一个围绕词元展开的全新经济形态——词元经济，正式从讨论的术语上升为国家层面的战略概念。

一个原本只活跃在技术开发者文档里的专业词汇，为何突然站到了经济舞台的聚光灯下？它包含哪些层次、哪些产业链？它又将如何重构产业版图，背后机会在哪里？这篇文章，我们就把这些问题说清楚。

这个话题稍微有点门槛，我尽量用大白话说清楚，但它对你理解未来非常非常重要。

好，我们开始。

可被度量的“智能”

要理解词元经济，首先要回到一个最基本的问题：词元到底是什么？

从技术层面看，词元是大模型处理信息的基本单元。我们人类读书写字以“字”为单位，而AI处理数据时，会先将输入内容拆解为一个个可计算的词元。它可能是一个汉字、一个标点、一个词汇片段。打个形象的比方：词元就像是AI世界里的原子。我们人类用字和词来理解和表达思想，而AI用词元来计算和理解。

正因如此，词元成为衡量AI工作量最直接、最核心的指标。你让AI完成的任何任务（写文章、分析财报、生成代码），其工作规模都可以等价转化为模型需要处理的输入和输出词元总数。处理这些词元需要消耗实质的计算资源，因此，服务商通常会以处理或使用的词元总量为依据，进行计量和收费。

如果词元仅仅停留在技术层面，它不过是工程师关心的参数，真正让它“破圈”的，是它在商业世界中被赋予的经济属性。

英伟达创始人黄仁勋在2026年GTC大会上，提出了一个极具冲击力的论断，他说：“词元是新的大宗商品”。

在他的描述中，传统产业卖商品、卖服务，而AI产业的核心是“售卖智能”，词元就是智能的计量单位。数据中心不再是储存数据的“仓库”，而是全天候运转的“词元工厂”，输入电力和数据，输出词元，而且这个词元可计量、可定价、可交易。

正是在这个意义上，《学习时报》的文章说：词元经济，是指在生成式人工智能运行和应用过程中，以词元为基础计量单位，围绕模型调用、信息处理、成本核算、服务定价和价值转化所形成的一种资源配置方式。

也就是说，它是围绕“智能的量化”生长出来的一种全新经济形态。从金融分析到医疗诊断，从法律审查到软件开发，每一个需要人类用脑力完成的工作，都是词元经济的潜在市场。

词元经济的“五层蛋糕”

黄仁勋之前提了一个概念，认为AI的产业链可以用“五层蛋糕”来概括，从底层到顶层依次是能源电力层、芯片硬件层、基础设施与软件生态层、大模型层以及应用层。我认为，这也对应着词元经济的五层蛋糕。

**第一层：能源与电力，这是词元的“原材料”。**

根据相关资料，AI数据中心的电力成本占总运营成本的50%左右，甚至更高，可以说，大模型本质上是一个“吃电怪兽”。正因如此，黄仁勋才会提出“每瓦词元数”这一核心竞争指标，谁能用每瓦电力产出更多词元，谁就拥有更低的生产成本和更强的竞争力。这也解释了为什么中国西部地区廉价的绿电资源，正在成为词元经济的重要底座，甚至能让中国绿电以词元形式实现价值出海。

**第二层：芯片与硬件，这是词元的“生产设备”。**

GPU、存储芯片、光模块、液冷散热设备等，构成了词元工厂的物理产线。这其中，不同芯片在单位电力下的词元生成能力和推理速度差异巨大。

**第三层：基础设施与软件生态，这是词元的“生产调度系统”。**

这部分相对复杂枯燥，我们就不展开了。

**第四层：大模型，这是词元的“操作系统”。**

各大模型厂商正是词元经济中最直接的供给方，它们将底层的算力和电力“加工”成以词元计价的智能服务。OpenAI首席执行官奥尔特曼曾直言：“从根本上说，我们的业务，以及每一家AI模型提供商的业务，本质上都将变成出售词元”。

这一层的竞争核心是**“智能密度”**。同样是一百万词元，顶级模型能完成复杂法律分析和工业建模，而普通模型可能只能完成简单问答，价值差别巨大。

**第五层：则是应用层，这是词元的“终端消费场景”。**

它不仅是词元经济的最终价值实现环节，也是整个产业链持续运转的飞轮。从智能客服、AI编程助手到自动驾驶感知系统，从金融风控到工业质检，AI应用越广泛、越深入，词元消耗量越大，反过来就越能拉动上游各层的扩容需求。

总之，词元经济包含了一条横跨能源、半导体、云计算、人工智能和应用软件的全景式产业链。

词元经济的影响

那么，词元经济究竟会带来怎样的影响呢？我将从产业、地方和资本市场三个角度分别分析。

首先，产业层面，可以拆分成两个层次来看。

**第一个层次，是词元经济本身拉动的直接供应链。**

比如，中国日均词元调用量，从1000亿到140万亿的千倍跃升，对算力的饥渴正在以指数级速度释放。这就让这条供应链的每一环都在承接历史级的增量——从最底层的能源与电力，到GPU、AI服务器、光模块、液冷散热这些硬件设施，再到算力租赁和数据中心。研究机构IDC（国际数据公司）预测，到2030年，全球年度词元消耗量或较2025年增长超过3亿倍，年复合增长率高达3418%。

这个速度惊人到很难想象，我只能说，按照这个逻辑，上面说的这些产业链层面的需求将是极其庞大的，这也一定会反映到资本市场。

**第二个层次，是词元经济对其他行业的渗透和赋能。**

这层影响比供应链本身的增量更深远。关键是要抓住一个核心转变：当智能可以被标准化为可计量的词元，它就开始经历一场“基础设施化”的进程，就像电力在19世纪末，从工厂的自备发电机走进了公共电网。

这正是词元经济对各行各业最底层的改变，它把“智能”变成了像水、电、燃气一样的基础要素，可以精确计量、按需购买、随处接入。

比如，一家制造企业不需要自己训练模型，就可以用词元实时调用行业大模型来优化工艺流程；一家律所不需要自研AI，就可以用词元让合同审查覆盖全量案卷，而非抽样。而原本一所基层医院需要靠少数专家才能完成的高难度影像判读，可以被拆解为词元级的推理服务。

各行各业第一次有了一张清晰的智能成本收益表，让智能变成了每个行业都能纳入日常生产决策的可运营变量。这就是词元经济“赋能”的真正含义——它不是帮某个行业多了一个AI工具，而是把“智能”变成了一条随时可接入的基础设施管线。

**其次，从地方的层面而言，理解了上面两层产业影响，才能理解地方政府为什么突然对词元经济迸发出巨大的热情。**

从省级到地市到区县，许多地方都在行动。

比如，广东省委机关报《南方日报》报道说，“词元经济”正在广东找到完整的落地样本；《安徽日报》说，安徽加速拥抱“词元经济”；甘肃省的地级市庆阳，在打造全球“词元工厂”，并且被央视新闻专门报道；而武汉的江岸区，则要全力打造“Token经济第一区”。

各地争的其实是一个问题的答案：在智能成为生产要素的时代，一座城市的核心竞争力由什么决定？

答案很简单：廉价稳定的电力、充沛可调度的算力、独特高质量的数据，以及丰富的应用场景。

比如，西部地区的绿电之前只能通过特高压远距离输送，但在词元经济的逻辑下，电力不需要物理传输，可以就地转化为词元，无重量、无损耗、可全球实时交易。这等于给了能源富集区一次越过传统制造业、直接进入数字经济高附加值环节的历史性机遇。

而诸多大城市，争夺的是另一张牌——数据的厚度和场景的密度，这实际上是在圈定自己的数据和应用优势。所以，地方的热忱，是面向下一个竞争周期的战略卡位。

最后，我们再从资本市场的角度分析下。

词元经济对资本市场的影响，要在两个时间维度上分别理解：一是眼下的财富效应按什么顺序扩散，二是长期而言，估值体系正在发生什么深层变化。

先看财富效应的扩散路径。

词元经济引发的资本红利，是一轮清晰的“传导式”扩散。

最先启动的是上游算力基础设施，这是逻辑最硬、业绩兑现最确定的一层；第一波炒“挖金子的铲子”之后，市场开始向中游扩散，光模块等成为第二个焦点，因为词元的高频调用，要求算力网络具备低延迟、高带宽的传输能力；然后才是依赖生态成熟和商业验证的下游，大模型厂商、行业应用公司、语料数据企业等。

这个“上游基建——中游传输调度——下游应用数据”的扩散顺序，是资本按照业绩兑现的确定性，从高到低依次定价的必然结果。

但这只是故事的第一层，更深层的变化在估值体系。

过去资本市场的估值框架，建立在工业经济时代的生产要素之上，比如土地、厂房、设备、品牌、渠道。但在词元经济的坐标系里，一种新的资产形态正在浮出水面：一个企业所拥有的、可以被词元化的知识与流程。

比如，一家工厂沉淀了二十年的工艺参数，一个医院积累了上百万份病历。这些在传统会计科目里，最多会被记入无形资产，或很难被准确定价的东西，在词元经济中，就变得不一样了。它们不再是沉睡的档案，而是可以被转化为行业词元，或通过模型微调而产生持续经济价值的原材料。

国家数据局在4月明确提出，要“探索词元交易等新型交易模式，构建以词元为基础、可量化、可定价的数据集价值体系”，这实际上是在为一种新型资产的确认和流通铺设制度轨道。一旦这套框架真正落地，资本市场将被迫学习一套新的估值语言，那些藏在资产负债表外的隐性资产，将第一次有机会走向显性化。

总之，当看不见的智能可以被度量、被定价、被交易，资本的流向就不再仅仅追逐当下的利润，而是开始沿着智能的链条，进行一次面向未来十年的长期配置。
