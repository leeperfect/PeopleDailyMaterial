## 一、从课堂任务开始取用

新版首页是教师备课台。当前共有 99 套完整授课资料：原有 49 个热点全部补齐，并有 50 个补充课程主题。原来的 3 张样板保留。每套包含口语稿、分段讲解、课堂追问、练习题与答案、5 页课件提纲及来源，均处于“待试讲确认”状态。

| 课堂需要 | 页面操作 | 拿到什么 |
| --- | --- | --- |
| 临时补充一个案例 | 打开案例，点“复制讲稿” | 约 3 分钟口语稿，带日期、版本和来源 |
| 展开综合分析 | 选择“10分钟讲解” | 分段讲解、板书、学生可能回答、教师追问、参考要点 |
| 安排课堂训练 | 选择“20分钟 · 讲练结合” | 10 分钟讲解，加准备、作答、互评与反馈安排 |
| 发给学生练习 | 点“取学生练习单” | 事实材料、模拟题、作答区；默认不含答案和个人备注 |
| 补充既有课件 | 点“取课件提纲” | 按页组织的标题与要点，可选讲解备注 |
| 准备多个案例 | 点“＋ 备课”，进入“本次备课” | 调整顺序、命名课程、一次合并导出 |

3、10、20 分钟是备课建议，实际时间需结合语速、班型和互动人数试讲调整。模拟题均为教研整理，不是考试原题。课件提纲可以复制到现有 PPT，当前不生成 `.pptx`。

首页可以直接“导出全部教师稿”或“导出全部学生练习”。“全部热点”支持将筛选结果加入备课，也可以直接导出筛选结果。

本地离线材料目录为 `data/hotspot_teaching/exports/handouts/index.md`，包含 297 份 Markdown 材料（99 套 × 教师稿、学生练习、课件提纲），无需网页也可编辑。

## 二、复制、Word 与 PDF

“导出材料”会先打开预览，再由老师选择材料类型及是否附答案、来源、讲解与个人备注、个人口语改稿。

- **复制带格式内容**：优先复制标题、段落、列表和来源链接；适合粘贴到 Word、WPS 或支持富文本的编辑器。若浏览器不支持，会提示已改为纯文本复制。
- **复制纯文本**：适合粘贴进课件文本框、聊天或个人资料；保留内容和来源网址。
- **下载 Word**：生成可继续编辑的 `.docx`，带原生列表、来源链接与页码，多案例分开起页。
- **打印 / 保存 PDF**：向浏览器请求打印，再选“保存为 PDF”。部分内置浏览器不显示打印窗口；遇到这种情况，用 Chrome 打开本页，或下载 Word 后另存 PDF。

学生练习单默认不含参考答案、教师追问、个人备注或个人口语改稿。老师主动勾选“附参考答案”后，答案另页列出；发放前应查看导出预览。学生版和课件提纲仅纳入已完成新授课加工的案例；选中的旧版资料会显示未纳入数量。教师详稿仍可合并旧版教学卡。

## 三、保存自己的备课习惯

在“3分钟口语稿”下展开“按我的讲课习惯改一改”，输入即自动保存个人稿；原教研稿保留。个人稿会用于页面展示、讲稿复制及教师版导出，可在导出时取消“采用我的口语改稿”。恢复教研原稿前，工具会先下载一份个人改稿文本备份。

“我的备注”记录课堂提醒、学生反应和本地补充案例。备注、改稿、备课案例顺序、课程名称和最近取用记录仅保存在**当前浏览器、当前网址**，不会写回文章库，也不会自动同步到其他老师或设备。

换设备、换网址或清理浏览器前，在“本次备课”点“导出备课备份”。新设备可以“导入备份”；导入会合并案例，并保留当前浏览器已经存在的个人改稿和备注。如果浏览器存储不可用，页面会提示使用备份保存。
