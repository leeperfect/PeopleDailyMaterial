# 热点教学日报使用说明

更新日期：2026-09-13

## 一、从课堂任务开始取用

新版首页是教师备课台。当前共有 85 套完整授课资料：原有 49 个热点全部补齐，72 篇新资料归并为 36 个新增课程主题。原来的 3 张样板保留。每套包含口语稿、分段讲解、课堂追问、练习题与答案、5 页课件提纲及来源，均处于“待试讲确认”状态。

| 课堂需要 | 页面操作 | 拿到什么 |
| --- | --- | --- |
| 临时补充一个案例 | 打开案例，点“复制讲稿” | 约 3 分钟口语稿，带日期、版本和来源 |
| 展开综合分析 | 选择“10分钟讲解” | 分段讲解、板书、学生可能回答、教师追问、参考要点 |
| 安排课堂训练 | 选择“20分钟 · 讲练结合” | 10 分钟讲解，加准备、作答、互评与反馈安排 |
| 发给学生练习 | 点“取学生练习单” | 事实材料、模拟题、作答区；默认不含答案和个人备注 |
| 补充既有课件 | 点“取课件提纲” | 按页组织的标题与要点，可选讲解备注 |
| 准备多个案例 | 点“＋ 备课”，进入“本次备课” | 调整顺序、命名课程、一次合并导出 |

3、10、20 分钟是备课建议，实际时间需结合语速、班型和互动人数试讲调整。模拟题均为教研整理，不是考试原题。课件提纲可以复制到现有 PPT，当前不生成 `.pptx`。

首页可以直接“导出全部教师稿”或“导出全部学生练习”。“全部热点”支持将筛选结果加入备课，也可以直接导出筛选结果。

本地离线材料目录为 `data/hotspot_teaching/exports/handouts/index.md`，包含 255 份 Markdown 材料（85 套 × 教师稿、学生练习、课件提纲），无需网页也可编辑。

## 二、复制、Word 与 PDF

“导出材料”会先打开预览，再由老师选择材料类型及是否附答案、来源、讲解与个人备注、个人口语改稿。

- **复制带格式内容**：优先复制标题、段落、列表和来源链接；适合粘贴到 Word、WPS 或支持富文本的编辑器。若浏览器不支持，会提示已改为纯文本复制。
- **复制纯文本**：适合粘贴进课件文本框、聊天或个人资料；保留内容和来源网址。
- **下载 Word**：生成可继续编辑的 `.docx`，带原生列表、来源链接与页码，多案例分开起页。
- **打印 / 保存 PDF**：向浏览器请求打印，再选“保存为 PDF”。部分内置浏览器不显示打印窗口；遇到这种情况，用 Chrome 打开本页，或下载 Word 后另存 PDF。

学生练习单默认不含参考答案、教师追问、个人备注或个人口语改稿。老师主动勾选“附参考答案”后，答案另页列出；发放前应查看导出预览。学生版和课件提纲仅纳入已完成新授课加工的案例；选中的旧版资料会显示未纳入数量。教师详稿仍可合并旧版教学卡。

## 三、保存自己的备课习惯

在“3分钟口语稿”下展开“按我的讲课习惯改一改”，输入即自动保存个人稿；原教研稿保留。个人稿会用于页面展示、讲稿复制及教师版导出，可在导出时取消“采用我的口语改稿”。恢复教研原稿前，工具会先下载一份个人改稿文本备份。

“我的备注”记录课堂提醒、学生反应和本地补充案例。备注、改稿、备课案例顺序、课程名称和最近取用记录仅保存在**当前浏览器、当前网址**，不会写回文章库，也不会自动同步到其他老师或设备。

换设备、换网址或清理浏览器前，在“本次备课”点“导出备课备份”。新设备可以“导入备份”；导入会合并案例，并保留当前浏览器已经存在的个人改稿和备注。如果浏览器存储不可用，页面会提示使用备份保存。

## 四、来源与审核

资料来自人民日报 APP 评论和《人民日报》正式版。原始资料库只读；新的教学工作台写入 `data/hotspot_teaching/`。

原有 3 张样板保存于 `data/hotspot_teaching/editorial/lesson-pilots.json`，其余 82 套保存于 `lesson-library.json`，逐课编写依据保存在 `editorial/full-coverage/`，不会覆盖原教学卡。每条事实指向具体文章编号；媒体观点与教研分析分开。`source-snapshot.json` 记录编写时来源正文的校验值。重新生成时若发现来源正文变化，页面会显示“来源变化 · 待核验”，保留原稿供核对。

原来的 27 张已发布教学卡、18 期已发布日报和 9 期已发布周报保留内容及发布记录。这个历史状态不代表新授课资料已由老师批准。旧卡仍需核对自动匹配来源和通用分析；重新采集时，仅正文与关联用途未变的资料保留原关联审核标记。

授课资料的口语稿、题目、答案与讲解安排应经过教师试讲后再扩大使用范围。后续新增样板应沿用“事实核验—具体讲解—学生作答—教师追问—可迁移方法”的结构，不能只批量换标题。

## 五、更新与打开

采集完成后生成资料与静态网页：

```bash
python3 scripts/compile_hotspot_lessons.py
python3 scripts/build_hotspot_teaching_daily.py
node scripts/export_hotspot_lesson_handouts.cjs
```

打开本地工作台：

```bash
python3 hotspot_teaching_daily.py
```

默认地址：`http://127.0.0.1:8767`。网页显示“热点资料截至”和“工作台更新”两个日期，避免把页面生成时间误当作新闻发生时间。

2026-09-13 已同步现有本地库中的最新资料：APP 原文截至 2026-09-12，正式版原文与已归档热点截至 2026-09-06。新增的 72 篇 APP 资料（9 月 7—12 日）进入“最新资料”，可以搜索标题、查看摘要、打开原文和复制摘要与出处。72 篇全部关联对应课程，可以从资料页直接打开讲稿。图片文章不引用未核实的图中文字；已反转的资助故事标注纠正，原文仅供对照。课程仍保留独立教研审核状态。本次没有重新抓取 9 月 13 日新闻。

原版卡片审核仍使用 `scripts/review_hotspot_teaching_card.py`，其 reviewed / published 状态只针对旧版卡片，不自动批准新样板。
