# 公开发布稿用语安全规范

## 一、规则定位

本规范用于降低公众号、小红书、今日头条、公开课件和公开题卡的发布风险，不把任何非官方网络词表当作法律意义上的“违禁词表”。不同平台、账号资质、内容领域和发布时点的审核标准可能不同，因此采用“明确规避词 + 风险复核词 + 内容类别审查”的方式管理。

这是一套公开表达规范，不是规避平台审核的方法。严禁使用错别字、谐音、拼音、拆字、插入符号、图片替字等方式绕过审核。

## 二、适用边界

### 必须执行

- `data/articles/` 中准备公开发布的文章正文、标题、摘要和参考文章。
- `data/xiaohongshu/` 中的卡片标题、正文、发布文案和视觉文字。
- 准备公开使用的 PPT、课堂讲义、申论题卡、面试题卡、封面和平台草稿。
- 从得到大脑拉回后的二润稿，以及同步公众号、今日头条前的最终文本。

### 不得改写

- `data/raw/`、`data/core/`、`data/vault/` 中的原始文章、事实记录和机器检索合同。
- 法律法规、政策文件、人民日报原文的内部存档标题和正文。
- Article ID、原始链接、数据库字段等溯源信息。

如原始材料含有需要规避的表达，应在公开稿中转述，在内部教研复盘中保留准确来源。不能为了公开表达安全而篡改史料或污染事实层。

## 三、分级词表

### A 级：项目明确规避

以下规则是本项目的公开发布偏好。它们不等于对词语法律性质的判断。

| 类型 | 公开稿中避免直接出现 | 推荐处理 |
| --- | --- | --- |
| 特定政治人物姓名 | `习近平`，以及其他现任、历任国家领导人姓名 | 非必要不写；确需表达时改为“有关重要论述”“相关要求”等不造成身份误认的概括 |
| 中央党组织全称或简称 | `中共中央`、`党中央`、`中央政治局`、`中共中央办公厅`、`中央宣传部`、`中央网信办` | 根据事实改为“中央有关部署”“有关部门”“相关政策文件”“有关会议” |
| 容易造成权威背书误认的表述 | `官方指定`、`官方唯一`、`内部渠道`、`内部消息`、`独家授权` | 只有具备真实授权和可核验证据时才可使用；否则删除或改写为可核验事实 |

替换必须保持原意和事实边界。若替换会使主体、责任或法律效力发生变化，应删除该句、改用其他来源，或将相关内容仅保留在内部教研复盘中。

### B 级：营销和绝对化表达，必须结合语境复核

常见风险表达包括：

- `国家级`、`最高级`、`最佳`、`顶级`、`全网第一`、`行业第一`、`全国第一`、`唯一`。
- `史上最`、`永久`、`绝对`、`百分之百`、`100%`、`万能`、`零风险`。
- `权威认证`、`权威推荐`、`国家认可`、`指定教材`、`唯一标准答案`。

这些词并非脱离语境后一律违法。例如，“国家级自然保护区”可能是准确的法定名称。公开稿应重点检查其是否被用于商业宣传、效果保证、排名比较或无证据背书。能够用具体事实、数据、适用范围和来源表达时，不使用绝对化结论。

### C 级：公考培训和教学传播高风险表达

本项目不得使用下列表达招揽或承诺培训效果：

- `包过`、`保过`、`必过`、`保证上岸`、`提分保证`。
- `精准押题`、`押中原题`、`泄题`、`命题人透露`、`命题组参与`。
- `内部资料`、`内部题库`、`内部渠道`、`官方指定课程`。

可以改为可核验、有限定的教学表述，例如“适用于某类题型”“提供分析框架”“帮助理解答题逻辑”“基于公开材料整理”。不得暗示考试机构、命题人员或有关部门参与、推荐或背书。

### D 级：健康、金融等领域的保证性表达

即使文章不是广告，也应避免无证据的效果承诺：

- 健康类：`治愈`、`根治`、`无副作用`、`药到病除`、`百分百有效`。
- 金融类：`稳赚不赔`、`保本保收益`、`保证收益`、`零风险投资`。

涉及健康、金融、法律等专业领域时，应使用权威来源、说明适用边界，并避免把一般信息写成个体化诊断、投资承诺或确定结果。

### E 级：标题党、虚假来源和误导性包装

公开稿应尽量避免：

- 无事实支撑的 `突发`、`刚刚`、`重磅`、`定了`、`彻底`、`一文看懂`、`不看后悔`。
- 编造背景、拼接事实、伪造原创、虚构数据、虚假标注来源。
- 冒用党政机关、媒体、专家、学校或社会知名人士名义制造背书。
- 把评论写成消息、把推测写成结论、把尚未正式生效的文件写成现行政策。

## 四、参考文章处理规则

参考文章也属于公开页面的一部分，按以下顺序处理：

1. 优先选用能够支撑同一观点、标题中不含 A 级规避词的来源。
2. 若原题含 A 级规避词且其他来源足够支撑，公开稿参考文章中不列该篇，完整来源保留在教研复盘。
3. 若该来源不可替代，可采用真实、可识别的缩略题名，但不得改变文章主题、主体、事实或法律效力；教研复盘中保留原题、Article ID 和本地路径。
4. 不得用错别字、谐音、拆字或符号替代原题中的词语。
5. 法律法规或政策文件名称一旦缩写可能改变效力或造成歧义时，不在公开稿中强行改名，改用其他可公开来源，或停止发布并交由人工判断。

## 五、写作执行流程

1. **来源层保真**：先完整读取原文，资料层不改。
2. **成稿层转述**：正文只保留必要事实，使用准确、克制、可核验的表达。
3. **参考文献复核**：逐条检查标题和作者信息，优先换源，其次真实缩写，不可安全处理则移入内部复盘。
4. **自动预检**：运行 `python3 scripts/check_public_wording.py "<公开稿路径>"`。多个文件可一次传入。
5. **人工终审**：自动检查只能发现已配置词语，不能替代对语境、事实、平台规则和账号资质的人工判断。

## 六、替代表达示例

| 不建议公开使用 | 可选表达 | 注意事项 |
| --- | --- | --- |
| 某政治人物明确指出 | 有关重要论述强调 / 相关要求提出 | 原文主体对法律效力不可替代时，不作模糊替换 |
| 中共中央印发 | 有关方面印发 / 相关文件提出 | 涉及正式文件效力时优先改用政策解读来源 |
| 官方指定答题模板 | 依据公开材料整理的答题框架 | 不得暗示授权或唯一性 |
| 保证上岸 | 帮助理解题型与答题逻辑 | 不承诺考试结果 |
| 全网最权威 | 基于公开权威来源整理 | 同时列明可追溯来源 |
| 百分百有效 | 在特定条件下可能有助于 | 需要事实或研究支持，并说明边界 |

## 七、依据与维护

本规范依据公开的现行规则整理，不存在一份适用于所有平台、所有语境的官方静态“敏感词清单”。维护时优先参考：

- [《网络信息内容生态治理规定》](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm)：违法信息、不良信息及平台内容生态治理要求。
- [《互联网用户公众账号信息服务管理规定》](https://www.cac.gov.cn/2021-01/22/c_1612887880656609.htm)：账号身份、来源标注、虚假信息、冒用机构和新闻信息服务等要求。
- [《中华人民共和国广告法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)：绝对化用语，教育培训、医疗和投资类保证性承诺等要求。
- [《广告绝对化用语执法指南》](https://www.samr.gov.cn/cms_files/filemanager/samr/www/samrnew/hd/zjdc/202212/P020230105320440168586.pdf)：绝对化表述应结合广告语境、事实和消费者误导风险判断。

当平台规则、法律法规或用户明确偏好变化时，更新本文件和 `scripts/check_public_wording.py` 的词表；不要从来历不明的营销网站直接复制所谓“最新违禁词大全”。
