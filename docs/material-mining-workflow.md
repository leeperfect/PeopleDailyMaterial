# 人民日报素材信息挖掘规程

这份规程是在原有自动素材库的基础上做补充，不替代原文、自动批注、金句库和案例库。原有自动提取适合“找得到”，这份规程解决“讲得出、用得上、能持续输出”的问题。

## 一、这套规程解决什么问题

以前的整理容易出现三个问题：

1. 只按关键词归类，容易把文章粗略塞进“经济发展、民生保障、生态文明”等大主题里，看起来很多，真正备课时却不好用。
2. 只摘金句和案例，缺少“申论怎么转译、面试怎么出题、公众号怎么连续写”的二次加工。
3. 只看单篇文章，忽略同一天文章之间的互相支撑关系，导致专题少、不成体系。

新的挖掘目标不是“多摘几条”，而是把人民日报文章转成三类资产：

- 申论教学资产：观点、论证框架、案例、分论点、对策表达。
- 结构化面试资产：社会现象题、组织协调题、应急处理题、人际沟通题、基层治理题。
- 公众号运营资产：连续专题、选题标题、文章大纲、短视频口播角度。

## 二、基本原则

### 1. 原文和旧批注不删

所有新整理都以“补充”为主。原文、已有 `批注汇总`、已有金句和案例不删不改。

如果要写入单篇文章，统一追加到文末的 `## 我的教研标注`，不要改动原来的自动批注区。

### 2. 事实层和转译层分开

事实层保留文章本身的信息：日期、版面、标题、来源链接、稳定文章 ID 或 `source_url`。

转译层才写老师判断：适合哪个申论主题、能出什么面试题、公众号可以怎么写。

不要用标题当唯一标识。每条高价值素材至少保留日期、标题、版面、来源链接；后续能补 `article_id` 时再补。

### 3. 先判断用途，再决定是否深挖

不是每篇文章都值得深挖。先问五个问题：

1. 这篇文章有没有清晰的“问题-做法-成效”链条？
2. 有没有能迁移到考场的治理逻辑？
3. 有没有可讲给学员的典型细节、数据或人物？
4. 能不能转成一道结构化面试题？
5. 能不能变成公众号的一篇文章，或一个系列的一部分？

五个问题中至少命中三个，才进入深挖。

### 4. AI 先粗标，老师再筛选

AI 负责第一轮粗读、归类、提炼、拟题。老师负责判断是否符合教学重点、是否适合学员理解、是否值得进入课程或公众号。

不要让 AI 一次性标太多。每天先做一日复盘，再挑 5 到 10 篇高价值文章深挖。

## 三、每日挖掘流程

### 第一步：建立当天文章总表

读取当天全部文章，记录：

- 日期
- 版面
- 标题
- 字数
- 来源链接
- 已有批注情况

先不要急着摘句子，先看当天整体议题。

### 第二步：按教学主线粗分

优先使用下面六条主线，而不是只用“十大热点主题”：

| 主线 | 重点看什么 | 常见用途 |
|---|---|---|
| 基层治理与群众工作 | 群众诉求、接诉即办、协同处置、反馈闭环 | 面试社会现象题、申论基层治理 |
| 作风建设与反形式主义 | 表面文章、潜规则、指尖负担、正确政绩观 | 申论综合分析、面试干部作风 |
| 高质量发展与新质生产力 | 科技创新、产业链、AI 应用、传统产业升级 | 申论经济发展、公众号选题 |
| 民生保障与公共服务 | 医疗、托育、就业、阅读、养老、劳动者关怀 | 申论民生专题、面试服务群众 |
| 生态文明与绿色转型 | 双碳、能源、垃圾资源化、绿色消费 | 申论生态文明、公众号系列 |
| 文化与城市品牌 | 公共文化、城市精神、文旅融合、文明建设 | 申论文化自信、公众号轻专题 |

### 第三步：给文章打优先级

| 等级 | 标准 | 后续处理 |
|---|---|---|
| A | 有完整治理逻辑，能直接进课、出题、写公众号 | 做成教研卡片 |
| B | 有好数据、好案例或好表达，但逻辑不完整 | 作为辅助素材 |
| C | 信息较单一、宣传色彩较重、教学迁移弱 | 只保留索引 |

广告版、地方形象稿不是不能用，但要标明性质。可以取数据、结构和政策表达，不要直接当作中立报道论据。

### 第四步：每篇 A 类文章做一张教研卡

建议固定成这个格式：

```markdown
### 文章标题

- 优先级：
- 来源定位：日期 / 版面 / source_url
- 核心事实：
- 教学价值：
- 申论可用：
- 面试可用：
- 公众号可用：
- 不要误用：
```

“不要误用”很重要。它提醒自己：这篇文章不能只背句子，要注意适用边界。

### 第五步：把单篇文章连成专题

每天至少尝试形成 3 个公众号专题。专题不是简单凑文章，而是要有连续输出价值。

为了服务公众号日更，同一个大母题可以连续拆出多个不同切入点。判断标准不是“题目是不是同一类”，而是：

- 是否有新的问题场景，例如从“公共服务均等化”拆出“健康服务下沉”“儿童友好空间”“新市民服务跟人走”。
- 是否有新的治理链条，例如从“正确政绩观”拆出“新官理旧账”“考核指挥棒”“群众看见变化”。
- 是否有新的读者收益，例如同样讲“AI治理”，可以分别讲“定价规则”“真实场景”“隐私安全”“AI反诈”。
- 是否至少有 3 篇人民日报文章支撑，且每篇文章在这个切口中有明确作用。

只要满足这些条件，即使属于同一母题，也可以作为独立公众号选题进入选题库；重复度高但角度不够独立的，才合并为已有母题的续写素材。

专题命名建议：

- 一个大判断：例如“好治理不是留痕多，而是问题真的解决了”
- 一组文章支撑：3 到 5 篇
- 一个学员收益：看完能掌握一个答题框架
- 一个运营形态：公众号长文、视频号口播、小红书卡片

### 第六步：输出当天复盘

当天复盘至少包含：

1. 一句话总判断
2. 当天四到六条主线
3. A 类文章清单
4. 申论框架
5. 面试题库
6. 公众号专题库
7. 全部文章取舍清单

形成符合标准的新公众号选题后，默认直接同步到正式选题库：

- 写入 `data/core/material_assets.sqlite` 的 `content_ideas` 表。
- 刷新 `data/articles/选题库.md`。
- 刷新 `data/exports/content_ideas.csv`。
- 如存在精筛保留清单或去重脚本，也要同步补入，避免下次打开选题工作台时被自动筛掉。

## 四、准确性检查

每次整理完成后做一遍检查：

- 有没有把文章中的“事实”与自己的“转译”混在一起？
- 有没有用标题替代稳定来源？
- 有没有把宣传稿当作一般新闻使用？
- 有没有只写“大词”，没有写具体做法？
- 有没有给出学员可直接使用的答题框架？
- 有没有为公众号留下可连续输出的选题？
- 有没有保留原文和旧批注？

## 五、最小可执行动作

如果当天时间有限，只做这四件事：

1. 看完当天全部标题和版面。
2. 选出 5 篇 A 类文章。
3. 每篇写 5 行教研卡。
4. 形成 1 个公众号选题和 1 道面试题。

这样每天都能沉淀一点可用资产，不会把素材库变成“看起来很大、真正用时还得重新找”的资料堆。
