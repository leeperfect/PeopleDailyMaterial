# 热点教学日报：备课灵感库界面

本次于 2026-09-13 完成界面整理，参考 [Pinterest 设计说明](https://getdesign.md/pinterest/design-md)。原有妙搭应用地址与访问范围保持不变。

| 原来的呈现 | 现在的呈现 | 对备课的帮助 |
| --- | --- | --- |
| 深蓝导航和密集文字卡片 | 暖白背景、黑色选中态、红色操作按钮 | 让案例内容更醒目，减少界面干扰 |
| 首页资料概况占据较多位置 | 简洁开场、主题筛选与错落卡片墙 | 可以先浏览灵感，再选取课程 |
| 案例主要靠标题区分 | 原创主题插画封面，配完整标题、用途、日期 | 扫看时更容易识别教育、治理、民生等主题 |
| 搜索入口集中在资料库 | 顶部全局搜索，可按 `/` 聚焦 | 在任何页面都可以找下一堂课的案例 |
| 最新资料纵向长列表 | 圆角资料卡，保留摘要、讲稿入口和来源说明 | 便于从报道进入对应讲稿 |
| 手机导航入口拥挤 | 常用导航横向排列，其余入口可展开 | 保留所有归档功能，适应小屏浏览 |
| 讲稿、侧栏、弹窗样式较硬 | 舒展的阅读区、胶囊页签、统一导出预览 | 复制与导出材料更容易辨认 |

封面是概念性教学插画，不是新闻现场图片；未增加外部图片请求、字体服务或追踪脚本。浏览器原有的备课组合、个人改稿、备注和主题设置沿用原来的保存位置。

## 资料与功能校验

- 网页仍包含 85 套授课资料、72 篇最新来源。`data.json`、授课资料模型与导出模块的校验值与美化前一致。
- 原有 10 项资料检查通过；学生答案隔离、个人内容隔离、来源日期、讲稿选择与旧卡取用检查通过。
- 浏览器实测：首页主题筛选、全局搜索、组合筛选、空结果与清空筛选、加入备课和移除、10 分钟讲解切换、学生练习单预览与 Word 下载。
- “催捐”旧闻纠正与图片延伸阅读提示仍可见，学生版默认不带参考答案。
- 检查 1440 像素桌面、1024 像素平板、390 像素手机与 320 像素窄屏。页面无横向溢出，手机封面文字无裁切。
- 浅色、深色与手机导航展开/收起均检查。减少动态效果设置继续生效。
- 已覆盖发布原妙搭应用，线上复核 85 套资料、72 篇来源、全局搜索、学生版预览与纠正说明，页面未报告脚本错误。
